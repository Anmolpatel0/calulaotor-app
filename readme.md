
# 🧮 CalcFlow — Calculator & Unit Converter

A beginner-friendly Python application built using Streamlit.

## Features
- Basic arithmetic operations
- Distance, temperature, weight, length and volume conversion
- Currency exchange using Frankfurter API
- Error handling and input validation
- Modern dark-themed interface

## Requirements
- Python 3.10+
- Streamlit
- Requests

## Run locally

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Start the application:

```bash
streamlit run app.py
```

Open the local URL printed in your terminal,
usually http://localhost:8501.

## Deploy on Streamlit Community Cloud

1. Upload this project to GitHub.
2. Visit https://share.streamlit.io/
3. Connect your GitHub account.
4. Select your repository.
5. Set the main file path to app.py.
6. Click Deploy.

## Currency API

https://api.frankfurter.app/

The API does not require a key for this basic use.
